# Copilot Follow-Along — Pre-Built Agents

Copy-ready, role-based prompts for seven agents built by Microsoft in Microsoft 365 Copilot: **Researcher, Analyst, Prompt Coach, Idea Coach, Writing Coach, Career Coach and Learning Coach**.

**Live site:** https://fortheloveoflearning.github.io/prebuilt-agents/

- **Classification:** Public
- **Fictional company:** Contoso Home & Auto, a department retailer (automotive parts, tires, tools, home goods, outdoor equipment, sports gear, seasonal items)
- **Fictional loyalty program:** Compass Rewards (members earn Compass Cash)
- **Audience:** store and head-office teams who are new or light Copilot users
- **Duration:** 90 minutes to 3 hours

## What's here

| Path | What it is |
|---|---|
| `index.html` | The follow-along page: role filter, 35 prompts with copy buttons and follow-ups, capstone, day-one habits |
| `facilitator.html` / `DEMO-INSTRUCTIONS.md` | Setup checklist, run of show (3 hours and 90 minutes), answer key |
| `guide.html`, `draft.html` | Read-and-copy views of the two text documents |
| `files/` | Practice files: program guide, draft email, 3 CSV datasets |

## Publish with GitHub Pages

1. Upload these files to the root of the repository.
2. Go to **Settings > Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, then **main** and **/ (root)**, and select **Save**.
4. The site appears at the URL above within a few minutes.

## Reuse it

Everything is fictitious and free to reuse for training. Swap in your own scenario by editing the prompts in `index.html` and the files in `files/`.

Contoso Home & Auto and Compass Rewards are fictitious. Any resemblance to real organizations, people, products, programs or data is coincidental. Agent names and availability vary by license and admin settings. Not an official Microsoft publication.
